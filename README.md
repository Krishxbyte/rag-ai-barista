# RAG AI Barista

An AI-powered coffee shop assistant built with Google ADK, Gemini, Streamlit, and Google Cloud Run.

## Overview

This project demonstrates a Retrieval-Augmented Generation (RAG) application that uses a coffee shop menu dataset to provide grounded recommendations.

## Technologies

- Python
- Google Agent Development Kit (ADK)
- Gemini
- Streamlit
- Google Cloud Run
